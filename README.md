# Global Food Waste Reduction Network — delivery sandbox

**Training sandbox for ITWorx PMO workshops. All people, partners and data are fictional.**

This repository stands in for the delivery tracker of the *Global Food Waste
Reduction Network* programme used throughout the ITWorx "Claude for Project
Managers" workshop series. Attendees read it with Claude to compute a project
health report (Day 3, Lab 12). Nothing here is a real product, partner or person.

## How the data is organised

- **Milestones** are two-week sprints (Sprint 14-18) plus the **Pilot launch**
  milestone, whose description carries the baseline and re-forecast dates.
- **Labels**: `type:*` (feature / bug / task), `area:*` (listings, matchmaking,
  logistics-api, impact-dashboard, marketing, localisation),
  `priority:high|medium|low`, `blocked`, `scope-change`.
- Velocity is closed issues per sprint milestone. Blocked and scope-change are
  labels. Staleness is the issue's last update date.
